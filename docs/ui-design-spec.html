01 / STRATEGY

登录是生成前的门槛，不是进入产品的门槛。

门户承担第一次访问的信任与理解，工作台承担实际创作。两者之间用「立即开始创作」连接， 而不是把用户先送去注册。游客可以输入、选参数、看示例，只有生成动作触发登录。

PRINCIPLE 01

先创作，后登录

输入框从一开始就可用。登录 Modal 覆盖在当前页，草稿和参数保持原值，成功后自动继续。

PRINCIPLE 02

作品先行

门户首屏先给一支片，而不是功能列表。案例、封面和提示词比「AI 能力」四个字更有说服力。

PRINCIPLE 03

一个主界面

对话页就是产品首页。会话、分镜、生成进度和结果都在同一条创作流里，不把用户带进后台表格。

CREATE / EMPTY

第一屏就让人想输入

  • Enter 生成，Shift + Enter 换行。
  • 游客态不显示禁用按钮，点击打开登录。
  • 左侧栏用登录说明卡替代历史。

AUTH 登录 Modal

桌面 440px，圆角 20px，内边距 32px。标题是 `登录后继续生成`，正文说明提示词和参数已经保留， 下方给出一行草稿摘要。登录/注册用文字式分段切换，不用厚重 Tab。

  • 字段：账号、密码；注册：用户名、邮箱、密码。
  • 主按钮：`登录并继续` / `注册并继续`。
  • 错误在表单内说明；不用 Toast 作为唯一反馈。
  • 提交中锁定表单，仍允许关闭；关闭后草稿不变。
  • 移动端改为底部抽屉，最大高度 88vh。
不做假入口：后端没有忘记密码、社交登录、额度体系，设计稿也不展示这些控件。

03 / VISUAL

像一间关灯后的剪辑室。

大面积碳黑、暖白文字、钨丝灯色的行动点，少量青色用于技术状态。视频是唯一的高饱和内容， 界面退后。衬线标题只出现在门户和品牌语境，工作台保持无衬线的效率。

05 / COPY & MOTION

按钮说明结果，错误说明下一步。

语气直接、具体，像一位懂制作的同事。不用「一键」「魔法」「赋能」， 不用感叹号堆情绪，也不用 emoji 代替图标。关键错误必须在表单或卡片内说明。

MOTION 动效原则

120 MS

微交互

悬停、颜色、透明度。只改变一个属性，不做位移和弹跳。

240 MS

Modal

背景淡入，面板从 0.98 到 1。移动端从底部上滑，尊重减少动效设置。

480 MS

首屏

文案与画面错开 60ms，向上 12px。只播放一次，不阻塞阅读。

不要假装：生成进度只过渡真实百分比，不做无限扫光假装工作； 成功状态不做彩带或全屏庆祝。流式光标在减少动效设置下改为静态省略号。

PROTOTYPE 原型连接

  1. 门户 `立即开始创作` → 工作台游客空态。
  2. 工作台输入提示词 → 游客已填写态。
  3. 点击 `生成视频` → 登录 Modal（Overlay，不跳页）。
  4. 登录成功 → 生成中 → 完成；草稿摘要全程可见。
  5. 完成 → 已登录工作台 → 我的作品。
  6. 移动端菜单 → 抽屉；生成 → 底部登录抽屉。

STATE 草稿与登录闸门

  • useAuthGate 保存 reason、pendingPrompt、pendingParams。
  • 登录成功后执行一次 completeGate，执行完清空，防止重复提交。
  • 游客不调用 loadSessions，不建立 WebSocket。
  • useChatSocket 增加 enabled，只在有 token 时挂载。
  • 草稿写入 sessionStorage，键名 aivideo.create.draft。
  • 成功后清除草稿；失败保留；手动清空时同步删除。
type AuthGateReason = 'generate' | 'works' | 'expired';

interface AuthGateState {
  open: boolean;
  mode: 'login' | 'register';
  reason: AuthGateReason | null;
  pendingPrompt: string | null;
  pendingParams: Record<string, unknown> | null;
  openGate: (payload: {
    reason: AuthGateReason;
    prompt?: string;
  }) => void;
  closeGate: () => void;
  completeGate: () => Promise<void> | void;
}

API 当前接口与 P0 编排

P0 不改后端：登录成功后创建会话，发送消息；助手返回 videoIntent=true 后， 前端用同一段提示词和参数调用 /video/tasks，生成卡显示任务进度。游客阶段不请求任何受保护接口。
能力接口限制
登录 / 注册/auth/login /auth/register可直接复用
会话 / 消息/chat/sessions /chat/messages消息只接收 content，不含风格/比例/时长
视频任务/video/tasks接收 prompt 与 params，可轮询列表
实时进度/ws/chat已有 video.progress；游客不连接

P1 建议增加 creation 聚合接口，或在消息 metadata 中保存 videoTaskId， 让会话与作品形成稳定关联。当前会话消息与视频任务没有持久化关联，刷新后生成卡只在作品页恢复。

ACCEPTANCE 实现验收

  • 未登录访问 /create 可直接输入，不跳登录页。
  • 点击生成打开同页 Modal，提示词和参数不丢失。
  • 登录成功后自动继续，不重复提交。
  • 关闭 Modal 后草稿仍在；刷新后可恢复。
  • 已登录访问 / 直接进入 /create。
  • 游客不调用会话接口，不建立 WebSocket。
  • 生成卡按真实进度显示，不出现假阶段。
  • 失败后可以重试，提示词和参数保留。
  • 会话过期时保留草稿并重新打开登录。
  • 作品页能区分生成中、完成、失败。
  • 1440 / 1024 / 390 无横向溢出。
  • 键盘可完成输入、提交、关闭 Modal；焦点可见。
